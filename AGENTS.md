# Working on grafana-clickhouse-drilldown

This is a standalone Go application repository, deployed privately on
observability (see `README.md` and `docs/operations.md`). No hosted Git remote
has been created. Do not create a remote or change the AGPL-3.0-only license
without authorization and dependency review.

## Plan and implementation

The original OpenChamber implementation plan is complete. New scope needs the
user's request; do not silently drop constraints from that plan or these notes.

Target the queries actually generated by Grafana Logs Drilldown. Do not promise
full Loki or LogQL compatibility. Parse the whole query, validate every stage,
and use one shared parameterized SQL compiler. Unsupported syntax must return
explicit errors rather than incorrect or successful empty results.

Review actual licenses, Go requirements, and dependency cost before adding any
dependency or Loki package. Do not use Loki main or regex-based query extraction.

## Infrastructure access

The infrastructure handbook is in `/mnt/code/dev/frcv/infa`. Start with its
`inventory/README.md`, `inventory/hosts.md`, `observability/clickstack/README.md`,
`openbao/README.md`, and `AGENTS.md` before operating live infrastructure.

The handbook's `observability/clickstack/README.md` links this adapter's
runtime notes. The runtime directory's `README.md` on the host mirrors
`docs/operations.md` for the deployed build. Do not move, discard, or
overwrite unrelated uncommitted changes in the handbook checkout.

Live configuration is authoritative. The host is `root@observability.n.vpn`.
ClickStack runs under `/root/docker/clickstack`, Grafana under
`/root/docker/grafana`, and this adapter under
`/root/docker/clickhouse-loki-adapter`. The old trial is retired and archived
under `/root/docker/retired/`. Use ordinary Docker Compose on this host,
not the docker-nixos SecretSpec wrapper. Do not restart or recreate unrelated
services. Preserve database volumes and all ingestion pipelines.

Use the handbook's `OpenBaoClient` from `openbao/access.py` for credentials.
Current Grafana credentials are in `prod/observability`, fields `GRAFANA_URL`
and `GRAFANA_TOKEN`. `prod/grafana` belongs to a retired instance and must not
be used. Parse owner-only `~/.env` as data; never source or print it. Keep
credentials in memory and send them only to their intended service. Do not
print container environments, resolved Compose configuration, or credentials.
The agent AppRole is read/list only; do not use an emergency root credential.

## Deployment boundaries

The adapter runs on the existing `clickstack_internal` network, with a
separate non-default Grafana data source (UID `clickhouse-loki-go`) and a
separate restricted ClickHouse reader (`clickhouse_drilldown`). Keep queries
bounded for the 4 GiB host. Publish no LAN/VPN/public adapter ports.
Production log data must not be copied into disposable test Loki/ClickHouse
instances.

The existing `clickstack` SQL data source remains Grafana's global default.
Leave `clickstack-prometheus`, its shared query queue, the SQL Logs Explorer,
and collectors unchanged.

The old experimental adapter (UID `clickhouse-loki-test`) was retired on
2026-10-23 after acceptance. Preserve its narrowly scoped rollback material and
each deployed build's retained image, source archive and backups. Never run
broad prune, `down -v`, or broad recursive removal commands.

Update the infrastructure handbook's current operating notes when live
deployment or access changes. Distinguish tested behavior, known limitations,
and user confirmation. Never commit production log dumps or secrets.
